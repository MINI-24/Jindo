# Jindo Launcher

Android handheld game launcher for one or two screens.

## 기능 특징
- **싱글 / 듀얼 스크린**: 설정 > 화면 모드. 듀얼은 작은 화면에 목록, 큰 화면에 HERO·로고·시계 (AYN Thor 등)
- **카드 모양**: 포스터(세로) 또는 네모 아이콘, 가로·2행·3행·세로 목록 배치
- **고성능 리퀴드 글래스(Liquid Glass) UI**: 1080p/120Hz 지원
- **플랫폼별 롬 관리**: Switch, 3DS, PS Vita, PC Gaming, Android Native
- **하단 독(Bottom Dock)**: 6슬롯 커스텀, 자동 숨김 옵션
- **SteamGridDB 연동**: 박스아트, 로고, 히어로 배너 비주얼 피커
- **포커스 & 테마 커스텀**: 4모서리 강조, 네온 글로우, 액센트 컬러 피커
- **백업 / 복원**: 설정, 라이브러리, 아트워크, 배경음악(BGM)까지 ZIP 하나로
- **내장 업데이트**: GitHub 릴리즈 자동 감지 및 원클릭 업데이트
